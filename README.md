EquiCare Energy is an offline-first Flutter app for monitoring and forecasting solar-powered home energy. It reads live battery, load, and solar data from an ESP32 (or the Wokwi simulator), computes runtime and charge-time from real physics, raises local alerts, and runs a small on-device linear-regression model that forecasts next-hour load — beating a persistence baseline. Works fully offline with cached solar forecasts and on-device model weights.
